Prototipo — panorama 360 sintético a partir de elevación + satélite + edificios/árboles

Fuentes: Open-Elevation (SRTM) para relieve, Esri World Imagery para textura satelital, Overpass (OpenStreetMap) para huellas de edificios y árboles. Todo gratuito, sin API key. Esto es un prototipo aislado — no toca el visor real.
